# Security policy

Please do not disclose a suspected vulnerability in a public issue. Use
GitHub's **Report a vulnerability** flow in the Security tab of this
repository. Include affected versions, reproduction steps, and impact.

Only the latest released version receives security fixes. Developer ID,
notarization, GitHub release, and Sparkle private keys are kept outside this
repository. The committed `SUPublicEDKey` is intentionally public and is used
only to verify signed updates.
